# AWBO — Article Writer by Olha

A web app for writing scientific articles with every phrase linked to the exact passage in its source PDF.

- Article on the left (parts, A4 pages, styles, notes), PDF sources on the right
- Select a phrase, select the passage in the PDF, link them; click the phrase to jump to the highlighted passage
- Link a folder of PDFs (remembered in Chrome/Edge); see which sources are cited
- Import / export Word (.docx) with sources as comments
- English, Lithuanian, Russian

All articles, PDFs and notes stay in your own browser. Nothing is uploaded to this repository.
